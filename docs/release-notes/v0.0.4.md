## Highlights

A new **IcerBox** hoster and **HitFile registered-account** uploads; the wizard now **fits your selection to each account's live free space** so you can't queue more than fits; a numeric **per-file upload order** replaces package priority; a bounded **upload-retry layer** that never double-creates a file; **Force start** to re-upload over the limit; and a batch of grid, column, and Logs additions.

## New file hosters & sign-in

- **IcerBox** added — a custom Bearer-JWT REST API (email / password, no captcha) with its own upload flow and storage (used / available) reporting via the file-manager endpoint.
- **HitFile registered-account uploads.** HitFile was anonymous-only; you can now sign in (WebView/Turnstile), uploads attach your account, and storage used / quota is refreshed from the session.
- **Sign-in errors no longer stretch the form** — they show as a compact `Error: …` line with a **Details** dialog carrying the full server response.
- **Hxfile sign-in fixed:** the stale session cookie is cleared before each WebView login, and the bare-token API key is read from the account page.
- **Hotlink disabled:** free accounts cannot upload and the API key is unobtainable. Retained in-tree if that changes.

## Wizard: fit your selection to available space

- **Page 3 (Summary) now checks each selected account's free space** and unchecks the files that don't fit — keeping the largest that do — instead of letting you queue 25 GB into a 1 GB account. Over-capacity blocks **Next** until you trim the selection.
- **Per-hoster, independent file checkboxes**, with a **"N file(s) unchecked to fit"** clue so it's clear why files are deselected.
- **Live storage refresh:** each selected account's free space is re-checked when you land on the Summary page — without popping a sign-in window — and the fit updates in place.
- Clearer header (**"N of M files selected • X to upload"**) and a left-aligned grand-total footer (**"Total: N file(s) • X to upload"**) next to the buttons.
- **File-type icons** in the summary file list.

## Per-file upload order

- The per-package **priority** field is replaced by a numeric, **per-file upload Order** you can edit directly in the Uploads grid, with **Move up / down / to** and renumber commands; uploads run in that order.
- Order / Move strings localized across all six languages.

## Upload reliability

- A shared, **bounded retry layer** in the attempt runner that only retries faults which provably never created a file (mid-send body aborts, connect-phase failures) and **never retries a chunked upload mid-stream**.
- **Alfafile / Rapidgator:** auto-retry "state 3" finalize failures (server processed the body but created no file) behind a no-committed-file precondition; re-authenticate and re-poll on a 401 during `upload_info` (bounded by the poll deadline); include the raw `upload_info` body in errors; and recreate the destination folder when its cached id was deleted server-side.
- **HitFile** uploads retry on transient connection resets.
- Hardened the upload-test suite against parallel thread-pool starvation; unified user-cancellation to a single `Cancelled` outcome.

## Force start

- **"Force start"** on the Uploads context menu starts a queued upload even when you're over the concurrency limit. For an already-completed file it confirms, re-hashes, and re-uploads, and shows a distinct icon.

## Grids, columns & Logs

- **Account** column on the Uploads and History grids; **"Added at"** column on Accounts; **"Started at"** column on Uploads / History.
- Accounts grid **updates a row in place on Refresh** and keeps it selected.
- Logs HTTP grid gains **Method**, **URL**, and **Proxy** columns, **show / hide + reorder** columns, horizontal scroll, and opens details on **double-click** (or Enter).
- Per-column **Copy** now covers the whole multi-selection.
- Completion shows the **full bytes loaded** (fixes instant dedup hits reading as 0).
- Column renames for clarity: Uploads **"Duration" → "Elapsed"** and **"Save to" → "Path"**.

## Notes

- Still targets `net10.0-windows10.0.17763.0` (Windows 10 1809+); self-contained `win-x64`, delta auto-updates via Velopack.
