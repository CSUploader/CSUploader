## Highlights

Upload reliability against real-world Rapidgator behaviour, scheduling that respects per-package times, a redesigned wizard with a dedicated **Upload files** mode, and a long list of UI/persistence fixes.

## Upload pipeline & Rapidgator

- **Poll `upload_info` until `state` is Done or Fail** (3-minute budget, 1s → 5s exponential backoff). Single-shot calls used to fail with `file/upload_info failed (HTTP 200)` while the server was still processing the upload server-side.
- **Per-credentials login gate** so 100+ parallel uploads share one login round-trip instead of hammering the *"Frequent logins. Please wait 20 seconds…"* rate limiter.
- HTTP response **status code is now a dedicated column** on the Logs → Http tab — non-200 responses are spottable without opening the row details.

## Hashing

- Live **hash speed, progress, BytesLoaded and BytesRemaining** during the hashing phase. Hashing used to look stuck at 0 until the upload took over.

## Scheduling

- Toolbar **Start all uploads** respects per-package schedules — it no longer kicks off files scheduled for a future time.
- Right-click on a scheduled row reads **"Start now"** and overrides the schedule.
- New **Scheduled at** column on the Uploads tab; the value also shows on file rows for context.

## Upload wizard

- New **Upload files** mode for picking individual files via the multi-select dialog, alongside the existing directory flow.
- Mode picker + source UI + file list **consolidated into a single step**.
- Single **Add files** button (replaces the dual pick/add interaction), with case-insensitive dedup when appending to an existing list.
- Filter and **Select all / Deselect all** hidden in files mode (they're only meaningful for directory listings).
- **Dark theme** fixes: DatePicker on the schedule step, toast notification text.

## Status rollup & persistence

- Package status no longer **flips to Failed while siblings are still uploading**. Once every file is terminal, a mix of completed + failed reports the new **Done with errors** state.
- Persisted files restore **StartedDate / FinishedDate / Duration** — the *Finished* column survives a restart.
- Persisted packages whose source file is missing **load normally** and surface "file not found" via the runtime path when started, instead of being silently dropped at load time with a spammy per-file error.
- **Reset** right-click reliably wakes the scheduler (no more hangs at `HashQueued`).
- The `Package.DirectoryPath` field and its database column were removed — `SaveFrom` is derived from per-file paths.

## Copy

- Right-click **Copy → Copy** on a Package now includes **all child files** in the clipboard.
- All Uploads-tab columns (Name, Size, Hoster, Status, Progress) carry through in the TSV — the template columns used to come out empty.

## Logs

- **Clear logs** also empties the in-memory Logs-tab listviews, not just the persisted DB rows.

## Misc

- "Upload speed" typo fixed in the footer.
- Column-header right-click show/hide menu restored on the Uploads and History tabs.
