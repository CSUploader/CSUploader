## Highlights

**The wizard now tells you how long each host keeps a file.** A new **"Kept for"** column on the
File Hosters step shows each host's retention — a fact that matters as much as the size cap when
choosing where a file goes, and one that ranges from **one day** to **permanent** across the hosts
in this app. **42 of the 77 hosters** show a figure; every one of them comes from the host's own
published policy, never a guess.

## The "Kept for" column

- **A plain duration** — "3 days", "48 hours", "121 days" — means the host deletes the file that
  long after upload.
- **A duration with a star** — "30 days *" — means the countdown restarts on every download, so a
  file that keeps being fetched keeps living. The column header's tooltip carries the legend, and
  each starred cell spells its own rule out ("Deleted 30 days after the last download.").
- **"Permanent"** appears only where the host states it: catbox ("files never expire"), udrop
  ("no file expiry"), qu.ax and DropMB (this app asks for no expiry and the host confirmed it), and
  the paid tiers of a few others.
- **An em dash** means the host doesn't publish a retention period — an unknown, not a promise.
  Hovering anywhere in the cell says so. Several free tiers prune quietly, so an unverified blank
  is shown as exactly that.
- **The figure follows the account dropdown**, because retention is tiered more often than not:
  upload.ee keeps an anonymous file 50 days after its last download but a signed-in one 120,
  TeraBytez 30 against 365 for premium.
- **Sorting works the way you'd want**: longest retention first, Permanent above everything,
  unknowns grouped together rather than pretending to be the shortest.

Worth knowing before picking a host:

- **DailyUploads deletes a guest file one day after its last download** — the shortest figure in
  the app. Its registered tier gets 15 days.
- **Wormhole and Hostize keep a file 24 hours**, full stop — transfer services, not storage.
- **Filedot keeps a registered file 1000 days after its last download**, the longest finite figure
  here; its premium tier never deletes.
- **ufile.io guests get a hard 30 days**, while any account — even free — is permanent storage.
- **GigaFile's 300 GB uploads last 100 days**, the longest of its own options, which this app
  requests explicitly.

Every figure cites its source in the code — the host's plan table, FAQ, or an expiry measured off a
real upload — and where a host publishes nonsense (one FAQ gives its paid tier a *shorter* life than
its free one) or omits what the days count from, the column stays conservative instead of repeating
it.

## Fixes

- **The grid's scrollbar no longer covers the last column's values.** Avalonia draws the vertical
  scrollbar over the rows area, so the rightmost column always lost its edge to the track — visible
  as "Permanen" and "121 day" in the new column, though "Max parallel" had been quietly losing its
  edge before it. A gutter now carries the scrollbar.
- **The em dash's explanation is actually reachable**: its tooltip target was the dash glyph itself,
  a few pixels wide. The whole cell now shows the tooltip.

## Notes

- The column is localized in all six languages, like the rest of the wizard.
- Hosts whose pages are bot-walled, script-rendered, or simply silent stay unknown for now:
  Rapidgator, NitroFlare, MediaFire, MEGA, Turbobit, HitFile, the Keep2Share family, Webshare,
  FileCat and kshared among them. Their cells show the dash; a future pass can fill them in.
