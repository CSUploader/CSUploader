## Highlights

**CSUploader has been rebuilt on Avalonia UI.** The entire interface was reimplemented — moved off WPF onto the Avalonia toolkit on .NET 10 — while keeping the same layout, features, and workflow you already know. Your existing install **updates in place**: settings, accounts, and history carry over untouched, and the auto-updater, installer, and package identity are unchanged.

## Rebuilt interface

- Every screen was re-created to match the previous version: **Uploads**, **History**, **Settings**, the **upload wizard**, all dialogs, the **menu bar**, **dark mode**, **minimize/close-to-tray**, completion **toasts**, and the captcha/**WebView sign-in** flow. Same look and behaviour, now on a modern, actively-developed UI stack.
- The updater is unchanged — older builds (v0.0.6 and earlier) **auto-update to v1.0.0** on their next check with settings and data intact.

## New file hoster

- **Buzzheavier** — anonymous one-click upload, plus signed-in uploads (sign in through the in-app WebView).

## Accounts

- **A failed account check now auto-disables the account.** If a check comes back failed (wrong credentials, host unreachable), the account is unticked so it won't be used for uploads until you fix it and re-enable it.
- The Accounts grid columns are now **resizable**.

## Update checks

- **A failed update check now reports the failure** instead of silently reading as "you're on the latest." The manual **Check for Updates** names the reason when it can't reach the update source; a background check shows a brief notification once per failure and clears it on the next success.

## Notes

- Still targets `net10.0-windows10.0.17763.0` (Windows 10 1809+); self-contained `win-x64`, delta auto-updates via Velopack. Same `CSUploader` package identity, so older installs update in place.
