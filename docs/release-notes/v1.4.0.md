## Highlights

**Twenty-four new file hosters** — CSUploader now uploads to **77**, up from 53. Sixteen of them
need no account at all, bringing the no-login total to **forty-one**.

Also in this release: the upload wizard takes files from **any number of folders**, shown as an
explorer tree, and its hoster step can be filtered and ticked in bulk. And a sign-in that has quietly
run out is now caught at startup and switched off, instead of failing every file in a run.

## New file hosters

**No account needed** — pick "Anonymous" in the wizard:

- **GigaFile** — **300 GB**, the largest in the app by a wide margin, kept **100 days**. Its own page
  ships a 7-day default; CSUploader asks for the longest retention the host offers.
- **UploadNow** — 100 GiB, uploaded straight into Cloudflare R2 as a signed multipart.
- **FileMirage** — 50 GiB, chunked. Accounts work too, and are derived by signing in rather than by
  pasting a key.
- **Hostize** — 20 GB. ⚠ **Free links live 24 hours** — that is the plan, not a setting, and every
  upload logs its exact expiry. An account changes nothing here.
- **udrop**, **BowFile** and **MegaUp** — three more hosts on the YetiShare platform, 20 GiB each,
  anonymous or signed in.
- **UploadHive** — no per-file cap. A previous sweep had written it off; it takes guest uploads.
- **World Files** — 5 GB anonymous, 10 GB signed in, with no guest upload form on the site at all.
- **DataNodes** — 3 GiB, anonymous or signed in on the same path.
- **Filego** — 2 GiB, in three calls.
- **Filebin** — no per-file cap; a "bin" is the whole security model, so the link is the secret.
  ⚠ Files **expire after 7 days**, and the host's own expiry is logged per upload.
- **DropMB** — 512 MB per share, a Pingvin Share instance, anonymous or signed in. CSUploader asks
  for no expiry at all.
- **UpZur** — 200 MiB anonymous. No upload form anywhere on the site; both the node and the cap come
  from its limits call.
- **BtaFile** — 100 MiB anonymous, **10 GiB** signed in. It advertises no guest upload and takes one
  anyway.
- **Xubster** — 10 MiB anonymous, 500 MiB signed in, on nodes that move host *and* port between
  uploads.

**With an account:**

- **UploadGIG** — re-enabled. Its website refuses uploads from this client, but the API the host
  publishes accepts them, so that is what CSUploader uses now. 10 GiB of free storage.
- **DepositFiles** — 10 GiB per file.
- **Emload** — no per-file cap; storage is the limit, and the host pre-flights the size before a byte
  is sent.
- **SubyShare** — 5 GiB. Free accounts upload.
- **kshared** — no per-file cap.
- **FileStore** — 250 MiB. It ships despite a Cloudflare challenge on its front page, because the
  sign-in browser is what fetches the form.
- **FileCat** — 2000 MiB. Its entire API lives on a subdomain; the front page had it filed as
  unimplementable.
- **PreFiles** — 512 MiB.

**And an existing host gained accounts:** **UsersDrive** signing in doubles its cap, with no browser
window, and its anonymous route is untouched.

## Upload wizard

- **Add files from any number of folders.** The first step is now an explorer split — the folders and
  files you have added on the left as a tree, their contents on the right — instead of one directory
  at a time. Adding a second folder no longer replaces the first, and dropping files or folders onto
  the window adds them too.
- **Filter the hoster step** by name, and by whether a host takes anonymous uploads. Seventy-seven
  rows is a lot to scroll.
- **Tick every listed hoster at once** from the checkbox in the Use column header. It follows the
  filter — filter to "anonymous", tick the header, and you have ticked exactly those.
- **Next is disabled until a hoster is ticked**, rather than letting a run start that would upload
  nothing.

## Accounts

- **A sign-in that has expired is caught when the app starts** and the account is switched off, so it
  is not offered in the wizard and does not fail every file in a run. Switching it back on
  **re-verifies it** — opening the sign-in window where one is needed — rather than trusting the
  switch.
- **"Refresh all" checks up to ten accounts at once**, instead of one after another. Two accounts on
  the same host are still checked one at a time, because several of these sign-ins are rate-limited.
  It also stops short of opening a queue of sign-in windows: accounts that need a browser are
  reported, not opened.
- **The Add Account dialog checks the credentials before saving them**, so a mistyped password can be
  corrected on the spot instead of being stored and failing later. Editing an account re-checks it
  too, and no longer wipes a stored key.
- **Hosts with no sign-in are no longer offered** in the Add Account dialog.
- **A saved session is re-checked without reopening the sign-in window** when it is still good.

## Fixes

- The saved theme is applied **before the first window is built**, so a dark-theme start no longer
  flashes light.
- The **Xubster** icon was a seven-pixel sliver rather than a missing icon; the hoster-icon tests now
  fail an icon that is nearly all transparent.

## Notes

- **Assessed and rejected this cycle**, with the reason recorded so they are not re-investigated:
  pillows.su (a captcha per *file*), UploadHaven (registration itself is paid-only), WuShare (a
  standing shell, not a service), fastbit.cc (1 MB cap for registered users), Jumploads (a measured
  49-byte free allowance), File.AL (approval-gated), Filextras and Filestore.to (account-type
  blocked), CloudGhost (refuses uploads either way).
- **TakeFile** stays disabled, now for a second independent reason.
- **DropGalaxy** and **ShareMods** remain present in the code but disabled, unchanged from 1.3.0.
