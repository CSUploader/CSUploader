## Highlights

Ten new file hosters (the wizard is no longer Rapidgator-only), anonymous "no-login" uploads for GigaPeta and Hexload, a chunked upload protocol for modern XFileSharing CDNs, WebView2 captcha sign-in for hosters that need it, and account storage (used / available) surfaced in the Account Manager.

## New file hosters

- **Ten hosters added** alongside Rapidgator: **Alfafile, BRupload, Ex-Load, FileBoom, KatFile, TakeFile, Hexload, Hxfile, Hotlink, and GigaPeta.** Each plugs into the existing `IFileHosterPipeline` architecture with its own account verification and upload flow.
- Most of the XFileSharing-family hosters (Ex-Load, KatFile, TakeFile, Hexload, Hxfile, Hotlink) share a single `XFileSharingApiPipeline` base that talks to the `/api/account/info` + `/api/upload/server` JSON endpoints and bootstraps an API key from a signed-in session.

## Anonymous uploads

- **GigaPeta** and **Hexload** support uploading **without an account**. The wizard offers an "Anonymous" entry in the account picker whenever a selected hoster supports it, with no entry cluttering the Accounts grid.
- Anonymous selections **survive an app restart** — a queued anonymous file reloads as anonymous instead of erroring with "no account".
- Hexload anonymous uploads scrape a fresh upload server per file with a **cache-busted request** and retry across the host's rotating server pool, so a dead/0.0.0.0 server never wastes the upload (2 GiB per-file cap; no file-count limit).

## Upload protocol & reliability

- **Chunked XFileSharing upload protocol** for modern CDN-backed hosters (per-chunk `up.cgi` + `api.cgi` finalize), falling back to the classic single-multipart POST when a host doesn't advertise chunking.
- Multipart bodies are **reshaped to match a real browser** (field order, quoted `name=`, `Origin` / `Sec-Fetch-*` headers, a shipped User-Agent) so XFileSharing backends stop rejecting them.
- Uploads and account checks **refuse to run when "Use Proxies" is on but no proxy is available**, instead of silently going direct.
- The HTTP transcript now **captures per-request headers** (Cookie, Origin, …) so on-the-wire problems are diagnosable from the Logs tab.

## Accounts & sign-in

- **WebView2 captcha sign-in** for hosters whose login is captcha-gated (FileBoom's OAuth2 flow, the XFileSharing API-key bootstrap). The XFileSharing hosters replace the username/password fields with a single **Sign in** button.
- **Account storage (used / available)** is shown in the Account Manager, rendered in binary IEC units, with an explicit **Unlimited** state for hosters that report usage but advertise no cap, and a blank cell when storage is unknown.
- The **hoster icon** is shown in the Account Manager grid and the wizard.
- Added accounts appear **immediately with a "Checking…" status** instead of blocking the dialog on verification; unknown verification failures no longer paint green.

## Wizard & scheduling

- Package **priority is now a real scheduling primitive** (five bounded levels) rather than a cosmetic field.
- The wizard **validates each hoster's max file size and max files-per-package** before you can start, and groups the **Back** button with Cancel / Next.
- File-hoster lists are **sorted alphabetically** in both the Add Account and wizard UIs.

## Settings & UI

- **Connection Manager rework** with an Edit Proxy dialog and Settings-grid polish; reliable **dark title bar** across Windows 10 / 11 and a dark DataGrid editor.
- Settings confirmation-prompt rows are highlighted (and the Database buttons row no longer is).
- Double-clicking an account row opens **Edit Account**.

## Removed & disabled

- **FilesMonster** and **Filecloud** removed — FilesMonster only lets paid members upload and filecloud.io is dead.
- **FlashBit** and **ExtMatrix** are present in the codebase but **disabled**: FlashBit's storage tier serves an invalid cert and caps body size below our chunk size, and ExtMatrix's upload endpoint rejects bodies above ~27 MiB. Both will be re-enabled if their infrastructure is fixed.

## Notes

- Still targets `net10.0-windows10.0.17763.0` (Windows 10 1809+); self-contained `win-x64`, delta auto-updates via Velopack.
