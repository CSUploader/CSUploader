## Highlights

**The wizard now tells you which hosts make your downloaders solve a captcha.** A new **"Download
captcha?"** column on the File Hosters step answers the question that matters most to whoever you
share a link with: must they solve a puzzle before the host hands over the file? **71 of the 76
hosters** carry a verdict — every one sourced from the host's own pages, the host's own shipped
code, or a walked live download — never from guessing.

## The "Download captcha?" column

- **"Yes"** means the ordinary free/anonymous download flow gates the file behind a captcha the
  downloader must actively solve — an image code, a reCAPTCHA checkbox, an interactive Turnstile
  widget. 39 hosts say Yes, usually the premium-model ones: Rapidgator's own captcha page tells
  free users "Premium users download files without captcha codes!", SubyShare's plan table spells
  out "Solve Captcha on download: Free — YES", 1fichier's pricing lists "Captcha" for guests and
  "No captcha" for the paid tier.
- **"No"** means the ordinary flow was verified captcha-free. 32 hosts qualify — some because the
  share link *is* the raw file (catbox, qu.ax, Litterbox, FileGarden — nowhere to even put a
  captcha), some because the host says so outright (udrop's FAQ: "Do my downloaders have to wait on
  a timer or solve CAPTCHAs? No."), and some because a live walk of the free flow reached the
  bytes — or the final direct file link — with no challenge anywhere (MediaFire, Sendspace,
  Webshare, Gofile, DropMeFiles, Wormhole, Transfer.it and more).
- **An em dash** means the flow couldn't be verified — an unknown, not a "no" — and hovering the
  cell says so. Five hosts stay unknown: Ufile, Isracloud, Xubster and FileStore (their free flows
  were unobservable: premium-locked samples or bot walls), plus UploadNow (the inspected share-page
  bundle shows no captcha markup, but the flow never reached file delivery, so the claim stays
  unmade).
- **Wait timers and automatic browser checks don't count** — the column is about puzzles a person
  must solve, and the header's tooltip says exactly that. A host can be captcha-free and still make
  free downloaders sit through a countdown.
- **One verdict per host, not per account**: it reports what the *downloader* of a shared link
  faces, so unlike its three neighbours the cell ignores the account dropdown.
- **Sorting groups each answer together** — Yes with Yes, No with No, and the unknowns as their own
  block rather than pretending to be either.

Worth knowing before picking a host:

- **Platform family predicts nothing.** Six hosts on the same XFileSharing stock as the
  captcha-gated crowd run their free downloads captcha-free — Send.now, UpZur, Uploadrar, FILEAXA,
  DailyUploads and filehoster.io — which is exactly why every verdict was verified per site.
- **Several hosts whose retention stayed unreadable last release gave up their captcha answer
  anyway**: Rapidgator, NitroFlare, MediaFire, MEGA, Turbobit, HitFile, the Keep2Share family,
  Webshare, FileCat and kshared all carry verdicts now — three of them (Turbobit, HitFile, IcerBox)
  straight from their own shipped JavaScript.
- **The Keep2Share family (k2s, FileBoom, TezFiles) captcha-gates platform-wide**: the operator's
  own API docs captcha-gate the documented guest/free download flow across all three brands.

Each Yes/No declaration carries the crux of its evidence in the code, and the full research
register — verdict, confidence, check date and evidence per host — lives in
[docs/hoster-download-captcha.md](https://github.com/CSUploader/CSUploader/blob/v1.4.2/docs/hoster-download-captcha.md),
pinned to the pipelines by a test that fails the build if either side drifts.

## Changed

- **The hoster grid's columns are now resizable** — drag the header edges, matching the Uploads,
  Uploaded, Logs and Accounts grids. The Use checkbox and the scrollbar gutter stay fixed.
- **The three narrow capability columns slimmed down** to fit their values instead of their labels
  ("Max file size" 110→90, "Max parallel" 100→80, the new captcha column at 80), handing the freed
  width to the Account column. Labels that outgrow a slim column now wrap instead of clipping — in
  every language, not just English.

## Notes

- The column is localized in all six languages, like the rest of the wizard.
- Verdicts describe each host's *ordinary* flow: a handful of captcha-free hosts (Pixeldrain,
  DropMeFiles) arm a challenge only against flagged or rate-limited traffic, and that doesn't flip
  their "No".
- The five unknowns are researched-and-inconclusive, not unresearched — their reasons are in the
  register, and a future pass (or a host dropping its bot wall) can fill them in.
