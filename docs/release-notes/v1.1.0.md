## Highlights

**CSUploader now runs on Linux.** This release ships a portable **AppImage** alongside the usual Windows build — the full app, including the in-app captcha/sign-in browser, on a single self-contained file. On Windows everything updates in place as always.

Also in this release: **large-file uploads to Storage.to**, a big **responsiveness overhaul** for 500+ file queues, **package renaming**, and paste-ready **link export** for posting.

## Linux

- **Portable AppImage** (`CSUploader.AppImage`): download, `chmod +x`, run — no installer, no dependencies. Auto-updates arrive through the same release feed as Windows.
- The **hoster sign-in browser** works on Linux via a bundled Chromium (CEF) — including keyboard input and captchas.
- Settings, accounts, and history live in the standard per-user data directory (`~/.local/share`).

## New features

- **Copy Links** — right-click a completed package (Uploads or History) and copy its links as paste-ready text: grouped **by file** (mirror lists) or **by hoster**, as **plain text**, **BBCode**, or **Markdown**.
- **Rename packages** — F2 on a package row (or right-click → *Rename Package…*) edits the name inline; the rename persists and History picks it up.
- **Remove All Completed** — one context-menu sweep drops every finished file (and fully-finished packages) from the queue, with an opt-out confirmation like the other prompts.
- **Upload Overview** gains **Elapsed** (how long the current run has been going; freezes at the batch total when it finishes) and **Finish at** (the projected wall-clock completion time).
- **Speed sparkline** — a JDownloader-style mini graph of the last ~10 seconds of throughput next to the speed readout.
- **Wizard polish** — live total-size/selected-count footer on the Directory step, the Scheduler prefills date+time to *now*, clearer account dropdowns, and the "unchecked to fit" notice only counts real space evictions.

## File hosters

- **Storage.to** — large files now upload via Cloudflare R2 **multipart**, removing the previous single-request size ceiling.
- **Upstore** — the free/guest per-file cap is now correctly **1 GiB** (oversized files are rejected up front instead of after a long doomed upload), with groundwork laid for the premium 5 GB tier.
- **gofile.io** — recovers automatically when the cached guest account was purged server-side, and retries the upload on transient gateway errors (the intermittent *"Error forwarding request to upload server"*).
- **GigaPeta** — uploads are serialized (their nodes reject concurrent uploads), and a 403/5xx verdict now retries against a freshly assigned upload node.
- **wormhole.app** — transient storage errors (HTTP 500/503/408/429) retry per-part instead of failing the file.
- **KatFile** — sign-in fixed (moved to katfile.biz); XFS-based sign-ins now wait for the post-login navigation before capturing the session.

## Performance

Large queues (hundreds of files, ~20 running) are dramatically smoother:

- The periodic refresh now updates **only the rows that changed** and computes the Overview totals in a **single pass** — and skips entirely while another tab is showing.
- Expanding, collapsing, adding, or removing a large package is a **single grid update** instead of thousands (no more multi-second freezes on 2,000-file packages).
- The History tab no longer rebuilds itself on every completion while you're not looking at it.
- Log tabs are capped at the most recent 5,000 entries per tab and retain roughly half the memory per entry — long sessions no longer grow without bound.
- Directory scans in the wizard are linear again (no O(n²) footer recomputation), and completed rows restored at startup show **100%** instead of an empty bar.

## Fixes

- **History**: right-clicking a package now reliably selects it (and its files) so *Remove* works on the whole package.
- Re-queued failed files no longer display the previous attempt's Elapsed/progress while waiting.
- Proxy handling: **Use Proxies** defaults off, toggling it applies immediately, and pinned proxies honour the global toggle.
- Changing **max simultaneous uploads** takes effect immediately.
- "Use mock server" no longer defaults on in debug builds; assorted UI polish (column-header spacing, resizable/wider log columns, the uploading icon's shadow).

## Notes

- **Windows**: unchanged — `net10.0-windows10.0.17763.0` (Windows 10 1809+), self-contained `win-x64`, same `CSUploader` package identity; older installs auto-update in place.
- **Linux**: first release — portable AppImage, self-contained `linux-x64` (glibc), no installer. The app self-updates from the same GitHub releases.
- Builds are now **x64-only** across the solution.
