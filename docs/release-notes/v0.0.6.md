## Highlights

Eleven new file hosters — including three **end-to-end-encrypted, no-login** services (**transfer.it**, **mega.nz**, **wormhole.app**) and several one-click **anonymous** hosts (**catbox.moe**, **gofile.io**, **Storage.to**, **ufile.io**). Package **progress and ETA are now byte-weighted** across the whole package, the upload wizard shows a **per-hoster max file size**, and a high-severity **SQLite security advisory** (CVE-2025-6965) is cleared.

## New file hosters

- **transfer.it** — anonymous, **end-to-end-encrypted** upload over MEGA's protocol (an ephemeral session; there's nothing to sign in to).
- **mega.nz** — upload straight into your MEGA account's Cloud Drive with the same end-to-end encryption; used / free space is shown in the Accounts grid.
- **wormhole.app** — anonymous, **end-to-end-encrypted** WebTorrent upload; the share link carries the decryption key in its `#fragment`, which is never sent to the server. Files auto-expire.
- **Storage.to** — anonymous upload (presigned Cloudflare R2); 25 GB per file, auto-deletes after a few days.
- **catbox.moe** — **anonymous *and* logged-in** (userhash) uploads; files never expire. 200 MB per file, identical content de-duplicates.
- **gofile.io** — anonymous guest upload.
- **ufile.io** — **anonymous *and* registered** chunked upload. Registered tiers (Free / Pro / Business) get per-tier max file size, simultaneous-upload limits, and storage reporting.
- **MediaFire** — account upload with instant-link **de-duplication** (identical files link without re-uploading).
- **Pixeldrain** — account upload; the login key doubles as the API key.
- **File Garden** — account upload; skips re-uploading a file that already exists. 100 MiB per file.
- **Filehoster.io** — registered-account chunked upload (XFileSharing "xfspro"); 10 GB free tier.

## Uploads

- **Package progress and ETA are byte-weighted.** A package that's part-way through a large file now shows a true percent-complete and a whole-package time-remaining, instead of averaging per-file percentages while other files sit queued.
- The wizard's **hoster step shows a "Max file size" column**, so an over-sized selection is obvious before you start.
- The wizard **Summary** names the account's actual free space in the auto-fit notice, and shows it in **amber** (a heads-up) rather than info-blue.
- The Uploads grid grows a **horizontal scrollbar** when columns overflow, instead of clipping them.

## Accounts

- The **Used** column shows **"-"** for hosters that report no usage figure (rather than a blank cell), and **Available** shows **"Unlimited"** for hosts like catbox that genuinely have no cap.

## Security

- Cleared **CVE-2025-6965** (a high-severity SQLite memory-corruption advisory, NuGet `NU1903`): the bundled SQLite native library is updated past the fix (SQLite 3.50.4).

## Notes

- Still targets `net10.0-windows10.0.17763.0` (Windows 10 1809+); self-contained `win-x64`, delta auto-updates via Velopack.

## Changelog

### Added

- **Eleven new file hosters**: **transfer.it**, **mega.nz**, and **wormhole.app** (all end-to-end-encrypted); **Storage.to**, **catbox.moe**, **gofile.io**, and **ufile.io** (anonymous, several also logged-in); and **MediaFire**, **Pixeldrain**, **File Garden**, and **Filehoster.io** (account uploads).
- **ufile.io tiered accounts** (Free / Pro / Business) with per-tier max file size, simultaneous-upload limits, and storage reporting — backed by a new per-pipeline concurrent-upload cap and two new `AccountType` values.
- **"Max file size" column** on the wizard's hoster step.
- **Instant-link de-duplication** for MediaFire (identical content links without re-uploading) and a pre-upload existence check for File Garden.

### Changed

- **Package progress and ETA are byte-weighted** across the whole package instead of averaging per-file percentages, so a part-way-through large file reports true completion and a whole-package time-remaining.
- Accounts grid shows **"-"** when a hoster reports no Used figure and **"Unlimited"** for capless hosts (e.g. catbox); the wizard Summary names the account's free space in an amber auto-fit notice.
- The Uploads grid shows a **horizontal scrollbar** on column overflow rather than clipping.

### Security

- Cleared **CVE-2025-6965** (high-severity SQLite memory corruption, `NU1903`) by updating the bundled SQLite native library past the fix (SQLite 3.50.4).
