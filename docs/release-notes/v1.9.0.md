## Highlights

**The Upload Overview no longer flips between one row and two while uploads run.** When its figures
only just overflowed a row, the bar below the upload list flipped between one row and two every
second or two during an upload, and each flip resized the list above it. Now the bar can still gain
a row when a figure gets longer, but it doesn't give that row back by itself until the uploads end
or you pause them.

## What changed

- **A figure that gets shorter keeps its space while uploads are under way.** The Overview refreshes
  twice a second, and sizes and speeds drop trailing zeros (649.00 MiB is written 649 MiB), so a
  figure's width changes as it ticks. A figure that gets shorter now keeps its space, so the figures
  after it no longer slide back and pull the last one up a row; you may see a gap after it instead.
- **A figure that gets longer still gets its space straight away.** That can move a figure down a
  row as a number grows, and it doesn't move back up by itself while the space is held.
- **The space is held from the first queued file until the last one is done.** That covers hashing
  before an upload and the moments between one file finishing and the next starting. Pausing ends
  it too: once no file is queued, hashing or uploading, the figures close up again.

## What did not change

The Overview shows the same figures, in the same format, chosen from the same right-click menu, and
resizing the window still re-wraps it. Only the spacing while uploads are under way is new.
