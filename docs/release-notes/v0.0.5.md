## Highlights

Five new file hosters — **Isracloud**, **Keep2Share**, **NitroFlare**, **TezFiles**, and **Upstore** (anonymous *and* logged-in) — plus **Rapidgator** storage reporting; a fix for **non-ASCII (e.g. Japanese) filenames** uploading as `?????`; the **upload order** is now honored even when a file must be hashed first; context-menu actions apply to the **whole selection**; and a sweep that **disabled or removed a dozen dead or unusable hosters**.

## New file hosters

- **Isracloud** — a classic XFileSharing web-form host (no REST API): WebView session sign-in, the free tier's 5 MiB per-file cap enforced up front, and 10 MiB storage used / quota shown.
- **Keep2Share** and **TezFiles** — sister sites of FileBoom on the same "moneyplatform" `/v1` backend, shipped via a shared pipeline base: WebView access-token sign-in and the same upload + storage flow.
- **NitroFlare** — a reCAPTCHA WebView sign-in yields a durable account hash; cookieless upload to the assigned server; storage used / available scraped from the member dashboard. 10 GB free per-file cap.
- **Upstore** — both **anonymous** and **logged-in** uploads. Anonymous needs no account (a Dropzone-style POST); an added account (email / password) links uploads to your account and reports used storage (free space is unlimited). 2 GB free per-file cap.

## Storage

- **Rapidgator** now reports **used / available** storage (read from the login response) in the Accounts grid and refreshed live in the upload wizard.

## Fixes

- **Non-ASCII upload filenames** (Japanese, etc.) no longer arrive on the server as `?????` — multipart filenames are sent as raw UTF-8, the way a browser does.
- **Upload order is respected** when the first file needs hashing before upload — it no longer leapfrogs a queued #1 to start #2.
- **Removing a package's only file** now removes the empty package row too, instead of leaving it behind.
- **Uploads / History context menus** — every action (Open URL, Stop, Skip, Reset, Open folder, …) now applies to all selected rows, not just the focused one; "Open source folder" highlights the file in Explorer.

## Hoster cleanup

- **Disabled** (kept in-tree for an easy re-enable): **TakeFile** — its whole domain sits behind a Cloudflare *managed* challenge that fingerprints the TLS stack, which a desktop HTTP client can't pass even after solving it in the sign-in browser; **UploadGIG** — uploads to the site aren't going through, so there's nothing to wire up yet.
- **Removed** dead, premium-only, or otherwise unusable hosts: Novafile, Openload, Rapidu, RareFile, ShareOnline, UbiqFile (also a Cloudflare wall), UniBytes, Uploaded, and WuShare — plus two stray icon assets.

## Notes

- NuGet dependencies updated to their latest versions.
- Still targets `net10.0-windows10.0.17763.0` (Windows 10 1809+); self-contained `win-x64`, delta auto-updates via Velopack.
